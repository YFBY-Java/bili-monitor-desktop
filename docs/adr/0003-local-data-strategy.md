# ADR-0003：SQLite 事务库、内容寻址原始存储、按需 DuckDB

- 状态：Superseded by ADR-0004；嵌入式数据方向由 ADR-0005 恢复并细化
- 日期：2026-08-22

## 背景

桌面应用不能要求用户维护 PostgreSQL 等常驻数据库，同时爬虫原始响应和分析数据可能快速增长。单一 SQLite 文件既承担高频事务又保存所有大 payload，会增加备份、迁移和损坏恢复成本。

## 决策

- SQLite WAL 保存配置、平台账号引用、任务、checkpoint、归一化实体、Agent run 和对象元数据。
- Alembic 管理迁移，升级前创建可恢复备份。
- 原始响应、截图、trace、导出和 Agent artifact 使用 SHA-256 内容寻址文件存储。
- 数据量达到分析阈值后，由后台 compactor 生成分区 Parquet；DuckDB 作为只读分析引擎按需启动。
- 业务写入永远先经过应用端口，不允许 UI 或 Agent 直接执行任意 SQL。

## 结果

- 安装后无需额外服务；
- 大对象可独立做保留、去重和校验；
- 分析能力可以增长而不改变事务模型；
- 需要维护数据库记录与对象文件之间的一致性检查和垃圾回收。
